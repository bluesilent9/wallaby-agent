# Local approvals

Server proposals must pass strict public message validation and local Core checks before a local approval is offered. Direct Agent identities are QR-pinned. A Mobile receives verification permissions, never Agent signing/transfer authority.

Signing requires review of the actual transaction, exact local policy, fee/output checks, a valid request deadline and a protected local passphrase prompt. Signing and broadcast remain separate actions.

Extinction preservation and deletion are separate phases. Preservation verifies public history in Core's Extinct wallet. Deletion rechecks the original local wallet policy, zero balances, signed preservation evidence and exact file identity, and requires local approval. Full local Extinct comparisons are enforced when present. Direct peer evidence is optional and compares every address/label and raw transaction record; matching examples use the same display as local evidence. Without a local or direct copy, deletion displays the preservation-elsewhere warning.

Disc burn, full read-back, physical-disc destruction and removal of local wallets retain their distinct local confirmations. Watch-only data never substitutes for missing private signers. Historic policies and LOST information remain part of preserved wallet history.
