## Remaining live integration

Dashboard V1 Build 9 now implements DASHBOARD_PREVIEW_UPDATE.md, including sender signature verification, frozen peer/challenge bindings, staged receiver relay, one paired transfer at a time, temporary busy handling and explicit fresh attempts. Its tests exercise this Agent's actual sender and receiver preview code. Dashboard Build 8 remains incompatible with that extension; use Build 9 or later. Cross-laptop full SSH/password/askpass authentication, Snap confinement, UFW policy prompts, router reachability and production desktop startup still need live validation with that updated Dashboard. The complete receive/restore logic and cryptographic preview are tested locally, but this is not a claim that a real laptop-to-laptop transfer passed. No independent security audit has been performed.

SSH prerequisites are intentionally guided OS operations: the Agent does not install or alter the system SSH server, firewall or modem. Closing a transfer closes the direct connection and temporary Agent socket, not an existing OS SSH daemon. UFW checks are read-only and conservatively classified; complex/unknown rules are not reported safe. Sender errors provide receiver/sender-specific advice and identify modem blocking only as a suspicion.
