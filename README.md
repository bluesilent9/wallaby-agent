# Wallaby Agent — Stable

No Stable application release has been promoted yet.

**[Wallaby Agent V1 source and the Ubuntu 26.04 LTS DEB installer are on the Development branch](https://github.com/bluesilent9/wallaby-agent/tree/Development).**

V1 provides per-user IPv6 SSH tunnels for Jellyfin and DDNS-GO, an HTML5 configuration page, and the Bitcoin Core node connection to Wallaby Dashboard. All three services start OFF on a fresh installation.

Use the Development documentation for installation, SSH trust/key setup and the server's IPv6 forwarding rules. The repository has two branches: Stable and Development.
